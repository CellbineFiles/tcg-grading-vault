======================================================================
  TCG GRADING VAULT (v0.93.2) — INSTALLATION & SETUP GUIDE
======================================================================

100% local TCG grading, cert scan, market value, and eBay bookkeeping
tracker. All data, photos, and spreadsheets stay on your own computer.

TIP: Need help? You can copy and paste this entire file into Gemini
(gemini.google.com) and ask for a step-by-step walkthrough! Tell
Gemini whether you are on Windows or Mac, and paste any error
message you see if you get stuck.

----------------------------------------------------------------------
1. PREREQUISITES
----------------------------------------------------------------------
- Python 3.10 or newer installed on your computer:
  Download from https://www.python.org/downloads/
  * WINDOWS USERS: During Python setup, make sure to check the box
    "Add python.exe to PATH" before clicking Install Now.

----------------------------------------------------------------------
2. WINDOWS 1-CLICK SETUP WIZARD (EASIEST!)
----------------------------------------------------------------------
1. Extract this entire zip folder to a permanent folder on your
   computer (for example: Documents\TCG Grading Vault).
   Do NOT run it directly from inside the .zip preview.
2. Double-click "setup_windows.bat".
3. Click "Install Now" in the Setup Wizard window.
   It automatically creates .venv, installs all required packages,
   installs Playwright Chromium for cert scans, and creates a
   "TCG Grading Vault" shortcut with an icon on your Desktop!
4. Click "Launch TCG Grading Vault" (or double-click the new Desktop
   shortcut anytime in the future).

----------------------------------------------------------------------
3. MAC / LINUX / MANUAL SETUP
----------------------------------------------------------------------
Step 1: Open Terminal inside the extracted "tcg_grader_tracker" folder.
Step 2: Create and activate a virtual environment (.venv):
            python3 -m venv .venv
            source .venv/bin/activate
Step 3: Install all required Python packages:
            pip install -r requirements.txt
Step 4: Install the Playwright browser (for PSA / BGS / CGC scans):
            playwright install chromium
Step 5: Start the app:
            ./start.sh   (or: python3 run.py)

The app opens automatically at http://127.0.0.1:8765
(if port 8765 is busy, run.py automatically picks 8766–8785).

----------------------------------------------------------------------
4. MOVING YOUR FOLDER OR UPDATING TO A NEW VERSION (KEEP YOUR DATA!)
----------------------------------------------------------------------
Your database and uploaded card photos are stored in the "data" folder
inside tcg_grader_tracker (data\tcg_tracker.db and data\uploads\).

- Moving your folder: Stop the app (Ctrl+C), move the entire folder
  anywhere you want (e.g., out of Downloads into Documents), and run
  "setup_windows.bat" (or delete .venv and run start.bat) if needed—
  your "data" folder stays 100% intact.
- Updating to a newer version: Stop the app, copy/overwrite the app
  files WITHOUT deleting your existing "data" folder, then press
  Ctrl+Shift+R (Cmd+Shift+R on Mac) in the app to refresh.

----------------------------------------------------------------------
5. OPTIONAL: SCREENSHOT OCR SUPPORT
----------------------------------------------------------------------
To import card lists from screenshots (.png/.jpg/.webp):
- Windows: https://github.com/UB-Mannheim/tesseract/wiki
- Mac:     brew install tesseract
- Linux:   sudo apt install tesseract-ocr
